# Contributing

## Branches
- `main` – stable, demo-ready code only
- `develop` – integration branch
- `feature/<short-name>` – one branch per feature (e.g. `feature/slack-bot`)

## Commit messages
Use short, clear messages: `feat: add document upload API`, `fix: handle empty Slack message`, `docs: update setup guide`.

## Pull requests
Open a PR into `develop`, fill the template, and get at least one teammate to review.
